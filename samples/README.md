# Sample models

Procedurally generated, not derived from anyone else's work, and placed in the
public domain. They exist so you can try the app without hunting for an STL.

| File | Size | Why it is here |
|------|------|----------------|
| `knot.stl` | 50 × 52 × 18 mm | A (2,3) torus knot. Thin, curved, 7040 triangles — it fits the bed and is the model the README screenshot shows. |
| `too-large.stl` | 251 × 260 × 92 mm | The same knot scaled up past the build volume, for checking the fit warning. |
